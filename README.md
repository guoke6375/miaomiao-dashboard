# 王苗苗的个人成长工作台

一个手机优先的个人工作台：今天待办、习惯打卡、体重、记账、目标、周复盘。
纯静态 HTML + 一个边缘函数（双端同步），数据默认存在本机浏览器，部署后可在手机和电脑之间对齐。

## 目录

```
index.html                    界面 + 逻辑（无构建步骤）
manifest.json                 PWA，加到手机桌面用
icon.png                      桌面图标
package.json                  只有同步后端需要的依赖（@edgeone/pages-blob）
edge-functions/api/sync.js    双端同步接口 → /api/sync
工作台配置.md                  功能清单、数据结构、风格参数（给后续迭代看的）
```

## 部署

必须**从 Git 仓库导入**到 EdgeOne Pages（不要用直接上传）：
同步后端依赖 npm 包，只有走构建流程时平台才会安装依赖。

- 框架预设：其他 / 静态站点
- 构建命令：留空
- 输出目录：`/`

部署后：

1. 电脑打开网址，确认能看到工作台
2. 访问 `/api/sync` 应返回 JSON 而不是 404
3. 手机 Safari 打开 → 添加到主屏幕
4. 设置 → 双端同步 → 填用户名（3-32 位）和密码（≥8 位）

## 数据

- 全部业务数据存 `localStorage`（命名空间 `bysdash:`）
- 同步时整体上传，服务端按 `id` 逐条合并，取修改时间更新的那条
- 云端明文存储，只有知道用户名密码的人能读；密码忘了无法找回，请定期在设置里导出备份
